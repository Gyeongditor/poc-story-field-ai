# integration_test

이 폴더에는 통합 테스트 및 예제 실행을 위한 Python 스크립트들이 포함되어 있습니다.

## 파일별 설명

- dalle_image.py : DALL-E 이미지를 생성하는 스크립트
- gpt_casual2formal.py : GPT를 이용해 문체 변환(캐주얼→포멀) 처리
- gpt_story.py : GPT 기반 스토리 생성
- main.py : 통합 실행 메인 스크립트
- main_docker.py : 도커 환경에서 실행되는 메인 스크립트
- stt_whisper.py : Whisper 기반 음성 인식 테스트
